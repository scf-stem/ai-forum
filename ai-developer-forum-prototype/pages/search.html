使用 LangChain RAG 处理 PDF 表格时，拆分策略应该怎么选？

文档里既有段落也有表格，直接按固定字符拆分会把表格行切断。尝试了 RecursiveCharacterTextSplitter 和 Unstructured，但表格召回率还是不稳定。

最佳回答

建议先用 Unstructured 的 partition_pdf 区分文本块和表格块，表格块用 HTML 保留结构，再用 parent-document-retriever 做 coarse-to-fine 召回，最后让 LLM 根据表格 HTML 生成答案。
